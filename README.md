# 💕 DevDate - Encontro com a Cara da TI

Um site de **date interativo e divertido** feito para pedir alguém especial para sair! Com um botão "Não" que foge do mouse e muitas surpresas no caminho. 💖

---

## 🎯 Funcionalidades

### ✨ O que o DevDate faz:

- **Convite interativo** com dois botões: "Sim" e "Não"
- **Botão "Não" fugitivo** - tenta clicar nele? Ele foge! 😂
- **Frases engraçadas** a cada tentativa de clicar no "Não"
- **Agendamento** - escolha a data e horário do date
- **Escolha da comida** - selecione o que vai comer (pode escolher vários!)
- **Confirmação** - resumo do plano com botão para copiar
- **Design romântico** com tema claro e anjos fofos em cada página
- **Responsivo** - funciona em celular, tablet e desktop
- **Animações suaves** - os anjos flutuam e o botão foge com estilo

### 🎮 Como funciona o botão "Não":

1. Você tenta clicar no botão "Não"
2. Ele **treme** (como se estivesse rindo de você)
3. Depois **desliza** para outro lugar da tela
4. Uma **frase engraçada** aparece
5. Depois de **20 tentativas**, ele desiste e fica vermelho
6. Mensagem: "😭 TÁ BOM! EU ACEITO!"
7. Você clica e vai para o "Sim" 😂
